A code-drawn newspaper front page summarizing the world news of Tuesday 24 November 2026 in a single deterministic PNG. The program draws everything itself (its own software rasteriser and baked glyph coverage) — no network, no randomness, no clock: two runs produce byte-identical output.

Entry for make.fun's [“Sum up 24 November's world news in one image”](https://make.fun/bounty/news-image-20261124) bounty ($100 in USDC, 50 places).

## Run

```
node main.ts
```

Writes the image to /output/entry.png (or $MAKEFUN_OUTPUT_DIR/entry.png). Node 22, no dependencies.
